---
title: CI runners
description: Run untrusted PR CI inside ephemeral Firecracker microVMs — no sandbox-escape risk.
---

PukuCloud can run each CI job in a short-lived sandbox. Use tokens in CI secrets and clean up each sandbox at the end of the job.

## Environment

```bash
export PUKUCLOUD_API_KEY=pds_abc123def456...
export PUKUCLOUD_API=https://api.pukucloud.ai
```

## Shell runner pattern

```bash
set -euo pipefail

sandbox_id=$(pukucloud -o json sandbox create --template base --ttl 1h | jq -r '.id')

pukucloud sandbox cp ./repo.tar.gz "$sandbox_id:/workspace/repo.tar.gz"
pukucloud sandbox exec "$sandbox_id" -- bash -lc 'cd /workspace && tar -xzf repo.tar.gz && cd repo && ./ci.sh'
pukucloud sandbox logs "$sandbox_id" --no-follow --stream both
pukucloud sandbox delete "$sandbox_id"
```

## TypeScript runner pattern

```ts
import { Sandbox } from "@pukucloud/sdk";

const sandbox = await Sandbox.create({
  template: "base",
  ttlSeconds: 3600,
  metadata: { kind: "ci" },
});

try {
  await sandbox.filesystem.upload("./repo.tar.gz", "/workspace/repo.tar.gz");
  const result = await sandbox.exec([
    "bash",
    "-lc",
    "cd /workspace && tar -xzf repo.tar.gz && cd repo && ./ci.sh",
  ], 1800);

  if (result.exitCode !== 0) throw new Error(result.stderr);
} finally {
  await sandbox.kill();
}
```

## Useful lifecycle controls

```bash
pukucloud sandbox pause <id>
pukucloud sandbox resume <id>
pukucloud sandbox set-ttl <id> 1h
pukucloud sandbox hibernate <id>
pukucloud sandbox wake <id>
```
